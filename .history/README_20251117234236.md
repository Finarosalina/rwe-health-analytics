# RWE Health Analytics Platform

A modular analytics framework for working with Real World Evidence (RWE) and electronic health records (EHR).  
The project is structured as a realistic healthcare data pipeline: from synthetic data generation to ingestion, cohort construction, exploratory analysis, and the foundation for downstream modeling (risk prediction, survival analysis, and causal inference).

---

## 1. Overview

This repository provides a reproducible environment for analysing longitudinal, patient-level healthcare data.  
It follows principles commonly used in pharmaceutical R&D, HEOR, and clinical analytics:

- Structured data ingestion and validation  
- Cohort definition logic  
- Domain-aware exploratory analysis  
- Separation between data, code, and models  
- Extensible package-like codebase under `src/`  

The project currently uses synthetic EHR-like data, but the architecture supports real datasets with minimal adaptation.

3. Data Flow

The system follows a linear, modular data lifecycle:

Data Generation
Synthetic patient-level data (demographics, diagnoses, labs, medications, outcomes) is generated using clinically-inspired distributions and event logic.

Data Ingestion
HealthcareDataLoader reads and validates the raw tables and exposes convenience methods for:

loading individual domains

patient-level retrieval

data quality checks

basic cohort creation

Exploratory Analysis
Jupyter notebooks provide statistical summaries, distribution analysis, event timelines, and preliminary clinical insights.

Modelling Layer (to be expanded)
The structure is prepared for:

survival analysis

risk prediction models

clustering and stratification

causal inference estimators

The intent is to maintain a separation between data, logic, and analysis.

5. Synthetic Data Generation

Run:

This creates:

data/raw/
    demographics.csv
    diagnoses.csv
    lab_results.csv
    medications.csv
    outcomes.csv


Overview:

The project includes a fully custom synthetic data generator designed to emulate electronic health records (EHR) and real-world data (RWD) structures while containing no sensitive patient information.
The generator produces a complete relational dataset with five tables:

Dataset	Description
Demographics	Age, gender, race, BMI, smoking status, insurance type, comorbidities
Diagnoses	ICD-like conditions, chronic/acute labels, visit types, timestamps
Laboratories	Biomarker measurements with physiological ranges and abnormal flags
Medications	Prescriptions, dose, frequency, treatment duration, prescriber specialty
Outcomes	Hospitalizations, ER visits, death events, time-to-event variables

The data are created using:

realistic statistical distributions (normal, log-normal, Poisson, multinomial)

clinically plausible rules (e.g., diabetes increases glucose labs; comorbidities raise mortality risk)

temporal sequencing for visits, labs, prescriptions and outcomes

This synthetic dataset supports EDA, machine learning, survival analysis, and causal inference workflows without exposing any PHI/PII.
